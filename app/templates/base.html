Those dependencies are retired. The shim now forwards to the TRUSTSEAL authenticated design-system shell (layouts/app.html) so any template that still writes `{% extends "base.html" %}` renders through the modern layout without further changes. The blocks this shim honours: * `title` → page `` * `content` → authenticated page body * `login_content` → anonymous page body (merged into content; the anonymous-shell migration lives in layouts/auth.html for pages that need the full auth card.) * `module_header` → optional pre-content header block * `module_nav` → optional navigation block * `module_content` → optional module-body override Pages built against this shim will not look as polished as pages migrated directly to `layouts/app.html` — this is a safety net, not a target. Legacy list stubs (`<h1>List</h1>`) now render through the design-system shell instead of a broken Bootstrap+AdminLTE page.
