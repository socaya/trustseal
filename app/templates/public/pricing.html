Pricing

TRUSTSEAL is deployed as a single-tenant workbench. Pricing depends on the configuration your deployment needs — number of KMS signing keys, Time-Stamp Authority throughput, evidence-retention storage, SCIM provisioning, and whether SAML SSO is required. We do not publish headline plan tiers because they would be misleading for most deployments.

What you always get

  • Unlimited signing envelopes, participants, review receipts and sealed PDFs for the subscribed deployment.
  • Public verifier API + hosted public verification page.
  • Chained-hash audit log with signed anchors, validation dossiers and evidence retention.
  • Pluggable private-object storage (filesystem or S3/MinIO compatible).
  • OIDC SSO out of the box; SAML 2.0 SSO available per-deployment.
  • SCIM 2.0 provisioning, scoped API tokens, webhook delivery with signatures + replay.
  • Operator notifications, structured OpenTelemetry + Prometheus observability, X-Request-Id correlation.
  • A disciplined design system — the same shell you are using right now.

What drives price

KMS signing keys
Per-tenant managed keys for platform PDF seals. Additional keys (e.g. per-business-unit) increase the base cost.
Trusted timestamps (RFC 3161)
TSA throughput charged in request tiers. We pass through the actual TSA cost; we do not mark up timestamps.
Evidence retention
Storage for retained sealed PDFs, validation dossiers and revocation evidence. Priced per-GB-month or passed through from your S3/MinIO bucket.
Identity integrations
SAML 2.0 with SP-signed AuthnRequests, SCIM 2.0 provisioning to multiple identity providers, and federated Single Logout are available where required.
Operational support
Response targets, incident-handling cadence and break-glass operator access are tiered by the support plan.
